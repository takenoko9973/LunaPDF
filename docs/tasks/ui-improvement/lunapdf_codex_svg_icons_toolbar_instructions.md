# Codex向け LunaPDF SVGアイコン移行・ツールバー修正指示書

## 目的

現在のツールバーアイコンを、eguiの`Painter`による座標描画から、リポジトリ内の個別SVGファイルをコンパイル時に読み込む方式へ変更してください。

併せて、アイコンボタンの常時表示される枠線を削除し、ツールバー上のUndoボタンを廃止してください。

ページ番号欄などの文字を下方向へ動かす固定補正は、今回は追加しないでください。

本書は既存のUI改善指示書を置き換えるものではありません。ページ移動、検索、ハイライト、Undo、印刷、サイドバー、描画性能改善を維持し、今回指定した差分だけを変更してください。

## 対象

- リポジトリ：`takenoko9973/LunaPDF`
- 対象ブランチ：作業開始時点の`main`
- 主な変更候補：
  - `Cargo.toml`
  - `Cargo.lock`
  - egui初期化箇所
  - `src/ui/icons.rs`
  - `src/app.rs`
  - `assets/icons/`

作業開始時に、実際の構成、`AGENTS.md`、未コミット差分、最新の`main`を確認してください。実際の責務が上記と異なる場合は既存構造を優先してください。

## 制約

- ユーザーの既存変更を上書きしない。
- 本指示に関係しないリファクタリングを行わない。
- PDF描画、保存、印刷、注釈、検索、ページ移動の挙動を変更しない。
- フォントファイルを追加しない。
- SVGを実行時の外部ファイルとして必須にしない。
- PNGへ変換してコミットしない。
- Painter描画へ戻すフォールバックを追加しない。
- commit、push、PR作成を行わない。
- 実行していない検証を成功として報告しない。

## 1．文字位置の固定補正を追加しない

ページ番号欄、検索欄、ラベル、ツールチップについて、次のようなY方向補正を追加しないでください。

```rust
position.y += 1.0;
rect = rect.translate(egui::vec2(0.0, 2.0));
```

Win32の`EDIT`コントロールを模倣した固定ピクセル補正も追加しないでください。

今回の作業では現在のフォント選択、文字サイズ、`TextEdit`の標準配置を維持してください。SVG移行によってツールバー全体の高さや入力欄の垂直位置が偶発的に変わらないことを確認してください。

## 2．ツールバー上のUndoボタンを削除する

ハイライトボタン付近にある、ツールバー上のUndoアイコンボタンを削除してください。

削除対象：

- ツールバーへのUndoボタン配置。
- `ToolbarIcon::Undo`。
- UndoアイコンのPainter描画。
- Undoボタンのツールチップ。
- Undoボタンだけを対象とするテスト。
- `undo.svg`が追加済みなら、その未使用ファイル。

Undo機能そのものは維持してください。

維持対象：

- `Ctrl+Z`。
- 「編集 → 元に戻す」。
- タブごとの編集履歴。
- ハイライト作成の取り消し。
- dirty状態と保存状態の更新。
- 既存注釈を削除しない安全性。

「前のページ」ボタンは削除しないでください。

## 3．アイコンボタンの枠線を削除する

現在、各アイコンボタンに表示される四角い枠線を削除してください。

表示仕様：

| 状態 | 背景 | 枠線 |
|---|---|---|
| 通常 | 透明 | なし |
| ホバー | 薄い背景 | なし |
| 押下 | ホバーより濃い背景 | なし |
| 選択 | 薄い選択背景 | なし |
| 無効 | 透明 | なし |

`visuals.bg_stroke`または同等の外周ストロークを使用しないでください。

クリック領域は現在の28×28ポイント前後を維持し、見た目を小さくするために操作領域まで縮小しないでください。

次の境界は別物なので削除しないでください。

- ページ番号入力欄。
- 検索入力欄。
- PDFページ。
- ダイアログ。
- サイドバー。
- 機能グループ間のセパレーター。

## 4．アイコン固有のPainter描画を廃止する

`src/ui/icons.rs`にある、`line_segment`、`rect_stroke`、`circle_stroke`、三角関数による円弧生成など、アイコン形状をRust座標で作る処理を削除してください。

`src/ui/icons.rs`には次の責務だけを残してください。

- アイコン種別。
- アイコンとSVGリソースの対応。
- 共通のアイコンボタン表示。
- 有効、無効、ホバー、押下、選択状態。
- ツールチップ。
- アイコン寸法とクリック領域。

背景塗りの共通処理にPainterが必要なら、それだけは残して構いません。

## 5．アイコンを個別SVGファイルへ分離する

次の構成を基本としてください。

```text
assets/
└── icons/
    ├── sidebar.svg
    ├── open.svg
    ├── print.svg
    ├── previous.svg
    ├── next.svg
    ├── zoom-out.svg
    ├── zoom-in.svg
    ├── fit-width.svg
    ├── fit-page.svg
    ├── continuous.svg
    ├── single-page.svg
    ├── highlight.svg
    ├── outline.svg
    └── thumbnails.svg
```

現在使われているアイコンを確認し、不足がある場合だけ追加してください。未使用の予備SVGは作成しないでください。Undoボタンは削除するため`undo.svg`は作成しません。

### SVG共通仕様

- `viewBox="0 0 24 24"`。
- 背景は透明。
- 正方形。
- 単色。
- 原則`fill="none"`。
- 線幅を統一する。
- `stroke-linecap="round"`。
- `stroke-linejoin="round"`。
- 外周に十分な余白を取る。
- 18ポイント程度でも判別できる単純な形状にする。
- SVG内に文字や絵文字を使わない。
- 色は`currentColor`を使用する。

例：

```xml
<svg xmlns="http://www.w3.org/2000/svg"
     viewBox="0 0 24 24"
     fill="none"
     stroke="currentColor"
     stroke-width="1.8"
     stroke-linecap="round"
     stroke-linejoin="round">
  <!-- path -->
</svg>
```

現在のPainter座標をそのままSVGへ転記しないでください。特にHighlightは、斜線と短い太線だけの形状を踏襲せず、蛍光ペンまたはマーカーとして判別できる形へ作り直してください。

原則として、このリポジトリ用の単純なSVGを新規作成してください。外部アイコンセットを使う場合は、AGPL-3.0-onlyのリポジトリへ同梱可能か確認し、必要なライセンス表示を追加してください。SumatraPDFのSVGをコピーしないでください。

## 6．SVGをコンパイル時に埋め込む

SVGはソースツリー内では別ファイルとして管理しますが、実行時に`assets/icons/`を探索しないでください。

現在のegui／eframeと同じ0.35系列の`egui_extras`を追加してください。

```toml
egui_extras = { version = "0.35.0", features = ["svg"] }
```

不要な`all_loaders`、HTTP、ファイルローダー、一般画像形式の機能は有効にしないでください。

eguiの初期化箇所で、画像ローダーを一度だけ登録してください。

```rust
egui_extras::install_image_loaders(&creation_context.egui_ctx);
```

各SVGは`egui::include_image!`または同等のコンパイル時埋め込みAPIで参照してください。

概念例：

```rust
fn source(self) -> egui::ImageSource<'static> {
    match self {
        Self::Open => egui::include_image!("../../assets/icons/open.svg"),
        Self::Print => egui::include_image!("../../assets/icons/print.svg"),
        // ...
    }
}
```

実際の相対パスはファイル配置に合わせてください。

禁止する方式：

- 実行時の相対パス読み込み。
- カレントディレクトリ依存。
- インストール先へSVGをコピーする処理。
- SVG欠落時だけPainterへ戻す処理。
- ビルド時にPNGへ変換して、そのPNGをコミットする処理。

SVGが欠落している場合は、ビルド時に失敗する構成で構いません。

## 7．SVGアイコンボタン

既存の`icon_button()`呼び出しを保てる場合は、外部インターフェースを維持してください。

```rust
icon_button(
    ui,
    ToolbarIcon::Open,
    enabled,
    selected,
    "PDFを開く (Ctrl+O)",
)
```

内部では次を満たしてください。

- クリック領域は28×28ポイント前後。
- SVG表示領域は18×18ポイント前後。
- アイコンは領域中央。
- 色はeguiの現在テーマから取得。
- 通常時は透明背景。
- ホバー、押下、選択時は塗りだけを表示してよい。
- 枠線はすべての状態で表示しない。
- 無効時は弱い前景色。
- ライト、ダーク両テーマで判別可能。

アイコンごとの位置調整をRust側へ追加せず、SVGの`viewBox`と余白を揃えてください。

- 中ボタン自動スクロール。
- 単ページ表示のホイール移動。

Undoボタン削除後に、未使用のセパレーターや不自然な空白を残さないでください。
