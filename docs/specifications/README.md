# LunaPDF 現行仕様

このディレクトリを、LunaPDF の現行仕様を確認・更新する唯一の入口とする。ここにある仕様書が利用者向けの正式な仕様であり、初期設計書や個別の作業指示書・報告書は、その時点の計画や判断を示す履歴資料として扱う。記述が異なる場合は、現行仕様書に明記した採用状況を優先する。

## 文書一覧

| 文書 | 扱う内容 |
| --- | --- |
| [application.md](application.md) | コードで実装を確認した、現在の主要機能と操作 |
| [keyboard-navigation.md](keyboard-navigation.md) | 今回採用した矢印キー操作とキーリピートの正式仕様。実装状況も併記する |

旧設計書は [初期設計アーカイブ](../archive/initial-design/pdf-viewer-plan-design.md) に保管する。作業資料の所在は [docs/tasks の索引](../tasks/README.md) を参照する。

## 記述区分

| 区分 | 意味 |
| --- | --- |
| **実装確認** | 現行コードに該当する処理がある。GUI、OS入力、印刷などの実動作を確認した意味ではない |
| **動作確認済み** | 対象操作を実際に検証し、その範囲と根拠を記録している |
| **採用・未実装** | 正式な仕様として採用したが、現行コードにはまだ実装されていない |
| **要確認** | コードや利用できる資料から現状を確定できない |
| **対象外** | この仕様書が扱う範囲に含めない |

コードの参照、テスト宣言の存在、ビルド成功だけでは「動作確認済み」としない。実際に行っていない GUI、OS、プリンターの確認を行ったように記録しない。既存テストへの案内は、実行済みの証拠とは区別する。

## 仕様と実装の差異

実装済み機能は、コードで確認できる現在の動作・条件・制約を記す。採用した仕様が未実装または実装と異なる場合は、仕様の採用状況とコード上の実装状況を別々に記録し、差異を隠さない。過去資料にだけ書かれた計画や制約を、現行仕様へそのまま引き継がない。

## 更新規則

機能追加や動作変更では、実装と同じ作業で関連する仕様書も更新する。更新後はコード、参照先、相対リンク、仕様と実装の差異を照合し、検証していない操作を確認済みとしない。過去の資料を変更して現行仕様へ見せかけず、必要なら新しい正本から履歴資料へリンクする。
