LunaPDF for Windows
===================

LunaPDF は、複数の PDF をタブで開ける Windows 向け PDF ビューアです。

インストーラー版
------------------

- 管理者権限を要求せず、現在のユーザーの
  %LOCALAPPDATA%\Programs\LunaPDF へインストールします。
- スタートメニューにショートカットを作成します。
- デスクトップショートカットはインストール時に選択できます。
- PDF の「プログラムから開く」候補と Windows の既定アプリ設定に登録します。
  既定の PDF アプリ自体は変更しません。

ポータブル版
----------------

- ZIP を展開し、LunaPDF.exe を起動します。インストールは不要です。
- レジストリや既定アプリ候補は登録しません。
- 設定とセッションはインストーラー版と同じ
  %APPDATA%\LunaPDF を使用します。ZIP の展開先を削除してもこのデータは残ります。

基本的な使い方
--------------

- PDF を LunaPDF.exe へドロップするか、「ファイル」→「PDF を開く」を使います。
- コマンドラインでは複数パスを指定できます。
  LunaPDF.exe "C:\PDF files\first.pdf" "C:\資料\second.pdf"
- 既に LunaPDF が起動中なら、追加の PDF は既存ウィンドウのタブで開きます。
- インストーラー版の既定アプリ設定は、LunaPDF の
  「ファイル」→「既定の PDF アプリを設定…」から開けます。

ライセンスとソースコード
----------------------------

- LunaPDF のライセンス本文は LICENSE.txt を参照してください。
- 対応するソースコードは SOURCE-CODE.txt に記載しています。

注意
----

- 現在の配布物にはコード署名がありません。Windows が保護画面を表示する場合があります。
- アップデートは自動では行われません。
